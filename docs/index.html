CivitForge

High-performance, federated forge platform

Self-hosted forge software that competes with GitHub, GitLab, and ForgeJo. Federated architecture for infinite scale. Full Git hosting, issue tracking, wiki, CI/CD, and code search -- all built in Rust.

Get Started
Features

What it does

  • Git repository hosting

    Push, pull, fork, merge. Full protocol support with SSH and HTTPS.

  • Issue tracking with labels

    Bug reports, feature requests, milestones. Labels, assignees, priorities.

  • Wiki with version history

    Documentation alongside code. Every edit tracked and revertible.

  • CI/CD pipeline engine

    Container-based runners. Builds, tests, and deploys defined as YAML pipelines.

  • AES-256-GCM encrypted secrets

    API keys, tokens, and credentials encrypted at rest and in transit.

  • Full-text code search

    Fast indexed search across all repositories, files, and commits.

  • JWT auth with refresh tokens

    Short-lived access tokens, long-lived refresh. Secure session management.

  • Federated architecture

    Connect instances together. Users, repos, and issues span federated nodes.

Quick Start

Docker Compose

Save as docker-compose.yml and run docker compose up -d.

# docker-compose.yml services: civitforge: image: ghcr.io/wyattau/civitforge:latest ports: - "8080:8080" environment: DATABASE_URL: postgres://civit:civit@db:5432/civitforge REDIS_URL: redis://cache:6379 SECRET_KEY: change-me-to-a-random-string depends_on: - db - cache db: image: postgres:16-alpine environment: POSTGRES_USER: civit POSTGRES_PASSWORD: civit POSTGRES_DB: civitforge volumes: - pgdata:/var/lib/postgresql/data cache: image: redis:7-alpine volumes: - redisdata:/data volumes: pgdata: redisdata:

Open http://localhost:8080 when ready.
